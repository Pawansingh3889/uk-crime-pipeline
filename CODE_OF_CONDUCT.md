# Code of conduct

Be useful, be honest, don't be a jerk.

## Expected behaviour

- **Useful** — reports have reproduction steps. Feature requests
  describe the question the data should answer, not just a tool.
- **Honest** — if you don't know, say so. If you benchmarked, show
  numbers; if you didn't, say "I think".
- **Respect the audience** — researchers, journalists, and citizens
  are the end users of what this pipeline publishes.
- **Good-faith reading** — ask before assuming hostility.

## Not tolerated

- **Personal attacks** on the maintainer, contributors, or anyone
  CC'd in an issue or PR.
- **Harassment of any kind** — targeted pile-ons, unwelcome sexual
  attention, doxxing. Zero tolerance.
- **Commercial spam.**
- **Bad-faith reports** — filing issues to waste maintainer time.
- **Misrepresentation of the data** — publishing derived analyses
  elsewhere while attributing them to this project in ways that
  aren't accurate. The dashboards published under this project are
  the authoritative source for this project's claims.

## Scope

Issues, PRs, discussions, code review comments, and public
communication about the project on external platforms.

## Reporting

Abuse routes through the same private channel as security:

<https://github.com/Pawansingh3889/uk-crime-pipeline/security/advisories/new>

Subject line: "Code of conduct". Acknowledgement within 7 days.

## Enforcement

Three tiers:

1. **Private warning.**
2. **Temporary block** — days to weeks.
3. **Permanent block** — for harassment that resumes, or for threats
   / doxxing / serious breaches.
